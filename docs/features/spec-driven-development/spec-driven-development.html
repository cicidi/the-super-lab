01 · Requirement

The requirement is defined in the parent PRD. Four upstream problems drive it; the solution is a set of cooperating skills that carry the work through five artifacts.

Problem 1

The problem is often never defined

"iPhone 18 Duo or base?" omits use, budget, history, and preferences — so the answer cannot be accurate.

Problem 2

AI's value is discovering the unknown

Including the blind spots we do not know we do not know.

Problem 3

Decisions change and conflict

A budget moves from $2,000 to $1,000; multiple participants can assert different decisions.

Problem 4

The human and the document are the bottleneck

Files must be readable, findable, and scoped; large projects need specs split by boundary.
