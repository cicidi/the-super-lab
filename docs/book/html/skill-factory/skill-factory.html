Skill Factory

A curated, framework-agnostic collection of AI agent skills, each packaged as a self-contained directory with a SKILL.md. Any SKILL.md-aware agent can copy, fork, or move a skill between projects without modification.

01 · Requirement

Skill Factory serves three audiences: AI agent developers who create and share reusable capabilities; end users who extend an agent with vetted skills; and maintainers who own quality and versioning. The project grew through 126 documented decisions, from skill creation to import policy.

Goal

50+ production skills

Within six months of PRD acceptance.

Goal

<5% rejection

Pull requests rejected for format violations.

Goal

<30 min to first skill

Time for a new contributor to create a skill.

Goal

100% portable

No hard-coded absolute paths; config lives outside the skill.

Consolidation

One source per capability

CRUD sets, conversation branches, complementary merges — merged only where the source is shared.
