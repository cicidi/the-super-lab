Document Standard（PRD 入口）

Overview

document-standard 规定 spec 文档怎么写：有哪几种文档、放在哪里、文件怎么命名、编号怎么起、什么内容不能删。这些要求本身已经写在 parent PRD 里（PRD-B 到 PRD-F，以及 PRD-M 的可读性要求），具体做法写在 document-standard design。

本篇是入口文件。按 ARD-BQ，一种文档拆成分篇时，必须有一个入口文件链到各分篇。

Goals and Success Metrics

本篇没有单独的目标，目标见各分篇和 parent PRD。
