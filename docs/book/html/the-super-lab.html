The Super Lab

A curated collection of AI agent skills in SKILL.md format — framework-agnostic, opencode-native. Copy a skill, fork it, move it between projects; it just works.

general skills 15 personal skills 9 core features 2 source repo the-super-lab

What is a skill?

A skill is a self-contained directory with a SKILL.md file. It packages "how to do X" so any SKILL.md-aware agent can execute it. The source lives in this repository; the deployed copies live in the IDE configs, and changes are made here first.

Source of truth

Edit skills in ~/project/the-super-lab/, then deploy with walter-worker's install script or coworker sync. Never edit the deployed copies: they are overwritten.
